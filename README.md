### 💫 About Me

I am a Software Engineering undergrad at **NSBM Green University** with a passion for pushing the boundaries of what mobile devices can do. I specialize in merging full-stack development with on-device machine learning to create zero-latency, highly interactive consumer applications.

- 🚀 **Currently Building:** **La Vogue Vista** — a real-time virtual beauty app utilizing Flutter, Native Swift (OpenGL), MediaPipe, and TensorFlow Lite.
- 🎯 **Focus Areas:** Cross-platform architecture, Computer Vision, and On-Device ML.
- 💼 **Status:** Actively exploring and open to new software engineering opportunities!
- 📫 **Reach Me:** sachini.2005.wijesundara@gmail.com

### 🌟 Featured Project: La Vogue Vista

> An AI-powered virtual beauty ecosystem built from the ground up. Bypassing standard hybrid rendering, I implemented **custom Native Swift (OpenGL)** and fine-tuned **TensorFlow Lite** models to achieve zero-latency live makeup try-on and on-device hair color segmentation.
